# PEMTSbrothers — Institutional Memory

This repository preserves the historical record of
decisions, meetings, reviews, and reflections
within PEMTSbrothers.

Memory is treated as a first-class governance asset.

---

## What Lives Here

- Decision logs
- Meeting notes
- Reviews
- Amendments
- Lessons learned

This repository prioritizes accuracy, clarity,
and long-term accessibility over speed.

---

## Structure

- `/decisions/`
- `/meetings/`
- `/reviews/`
- `/amendments/`
- `/reflections/`

Each entry should reference relevant proposals
and governance documents.

---

## Integrity of Memory

Entries should not be rewritten to hide mistakes.
Corrections are made through new entries,
preserving historical context.
